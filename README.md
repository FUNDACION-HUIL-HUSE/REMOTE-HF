# REMOTE-HF

Herramienta de inteligencia artificial para detectar de forma automática patrones de exacerbación en pacientes con insuficiencia cardíaca crónica (*heart failure*).

## Sobre el proyecto

- **Captación de datos:** dispositivos no invasivos (Huawei Band 10) que registran de forma remota y continua variables fisiológicas como la frecuencia cardíaca, la saturación de oxígeno, el sueño y los pasos.
- **Diseño:** estudio observacional prospectivo y multicéntrico.
- **Coordinación:** Hospital Universitario Infanta Leonor / FIIBHUILHUSE, en colaboración con la Universidad Politécnica de Madrid (UPM).
- **Privacidad:** los datos se tratan seudonimizados, se sincronizan mediante Huawei Health Kit y se almacenan en infraestructura cloud ubicada en la Unión Europea.
